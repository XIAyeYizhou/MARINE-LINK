# 字卡 · 玻璃信使

iOS 极简玻璃风格（Glassmorphism）移动端字卡聊天网站。全站图标均为纯 SVG 线性图标，不使用任何 emoji。

## 打开方式

方式一（推荐）：直接双击打开 `index.html`（Chrome / Edge / Safari 均可，数据保存在浏览器 localStorage）。

方式二：本地静态服务器

```bash
cd 本项目目录
python -m http.server 5173
# 浏览器访问 http://localhost:5173
```

## 目录结构

```
index.html          入口页面
styles.css          玻璃风格设计系统
js/icons.js         纯 SVG 图标库（无 emoji）
js/data.js          数据层（种子数据 + localStorage 持久化 + 模拟时间流速）
js/audio.js         WebAudio 引擎（音效 / 语音合成 / 音乐播放器）
js/ui.js            浮窗 / toast / 确认框 / 滑块 / 开关等组件
js/router.js        路由（move in / move out 页面切换）
js/ai.js            对方 AI 行为调度（自动回复、状态、头像、朋友圈、信件、红包、通话、戳一戳、打卡、礼物）
js/page-messages.js 信息页（搜索、左滑置顶/屏蔽/删除）
js/page-contacts.js 联系人页（新建联系人/群聊、资料、字卡编辑器、表情包、头像库、群设置）
js/page-chat.js     对话页（气泡、长按菜单、拍一拍、表情包、红包、视频/语音通话、戳一戳、视奸、骰子、更多设置、搜索记录、备份导入）
js/page-explore.js  探索页（朋友圈、信箱、音乐播放器、打卡）
js/page-profile.js  我的页（资料、头像库、主题切换、Link 杂货铺）
js/main.js          启动入口
```

## 功能速览

- **信息**：搜索框居中；会话左滑出「置顶 / 屏蔽 / 删除」。
- **对话**：进入/返回为 move in / move out；消息气泡两侧显示双方头像（点自己的头像进我的页面、点对方头像进对方页面）；我的气泡颜色跟随主题；长按气泡可引用、删除、收藏；双击对方头像拍一拍（拍一采用系统提示 + 动效，与用户一致，无气泡框）；表情包发送无气泡框仅图片；输入框右侧为发送图片按钮；单聊下方依次为表情包、红包、视频/语音通话、戳一戳、视奸、扔骰子；群聊下方仅保留表情包、红包、视频/语音通话、扔骰子。聊天表情包浮窗内可**直接添加自己的表情包**（与联系人页面的对方表情包相互独立）。
- **状态**：联系人或你的每个状态仅存在 **24 小时**（到期自动消失，联系人到期后重新计算随机时间）；每位联系人对你每个状态只能点赞/点踩一次、评论一条字卡，你回复后对方才能再回一条；状态评论（含回复）超过 3 条自动滚动。
- **朋友圈**：每位联系人每条动态只能点赞/点踩一次、评论一条字卡，回复按轮次进行，不会无限刷屏；评论超过 5 条自动滚动。
- **通话**：视频/语音浮窗可拖动、可缩放、可收纳成圆形悬浮图标；来电为「轨道 + 滑块」拖动接听/拒接；接通后对方会随机播放语音文件；视频与通话互斥；群聊通话参考微信，通话页展示群友头像。
- **更多菜单（单聊与群聊为不同界面，设置类子弹窗叠在其上方不关闭）**：
  - 单聊：聊天/视频/通话背景、自动发送、回复字卡数量（1–6）、回复时间间隙（6–180 秒）、合并字卡回复、搜索聊天记录、备份/导入聊天记录、删除聊天记录。
  - 群聊：仅设置聊天背景、搜索聊天记录、备份/导入聊天记录、删除聊天记录。
- **联系人**：新建联系人/群聊（群聊至少 2 人，**含你**）；联系人资料（点击头像可更换、发送消息、朋友圈、字卡、表情包、头像库、删除）；字卡分交流/拍一拍/状态/日常/语音/emoji/颜文字，支持批量、导入/导出字卡文件、去重、分组，单组超过 5 行自动滚动；m4a 语音导入；群聊设置（自动发送、互相 @、禁言）。
- **探索**：朋友圈（点赞/点踩互斥、评论、自定义背景、发布）；信箱（999 字信件、草稿箱、对方 3~48 小时回信 10~30 字卡）；音乐播放器（播放列表、单曲/列表/随机、邀请一起听——点击上方头像可解除、显示一起听时长、浮窗——开启后自动回到探索页且浮窗常驻，点击恢复播放器、本地 MP3 导入）；打卡（日历打卡 + 时间轴打卡，对方每 2~8 小时打卡）。
- **我的**：白色圆角卡片布局；添加状态（仅配图模糊展示，24 小时有效）；编辑个人资料；头像库（可允许对方推荐头像）；主题颜色切换（**中性 / 粉色 / 蓝色 / 绿色 / 紫色 / 橙色 / 红色七组莫兰迪色系**，每组背景色均含默认 #D9D9D9，可微调字体/背景/UI 框架色并一键还原）；Link 杂货铺（自建商品、赠送联系人、次日 8:00 送达、对方自动回复）。

## 说明

- 本网站用于**实际使用**：初始没有任何演示人物，从「联系人」页自行新建联系人/群聊即可；所有周期事件（状态更换 2 天~1 个月、信件 1~30 天、头像更换等）均按真实时间运行。
- 我的气泡颜色为 #A0C7DB（浅蓝），整体参考微信交互。
- 所有数据保存在浏览器 localStorage，可随时刷新；删除联系人/群聊会清空对应数据。
